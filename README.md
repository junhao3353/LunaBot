# LunaBot

> ⚠️ **当前版本：v0.1 测试版**
>
> 本项目仍处于早期测试阶段，各项功能适配尚不完善，可能存在Bug和不稳定情况。欢迎提交Issue和PR。

基于 NapCat + DeepSeek API 的 QQ 群 AI 机器人，支持图文视频多模态交互、永久记忆、语音回复、抖音解析下载等功能。

---

## ✨ 已完成功能

### 🎯 核心功能

| 功能 | 说明 |
|---|---|
| **AI 对话回复** | 基于 DeepSeek API，支持思考模式（high），群聊@触发 / 私聊直接触发 |
| **图片识别** | 视觉模型看图说话，支持联网搜索，自动缓存图片 |
| **视频理解** | 自动抽帧 + Whisper 语音转文字，让 AI 能"看懂"群友发的视频 |
| **语音回复** | 火山引擎 TTS（精灵向导 2.0 音色）/ 微软 edge-tts 可切换，回复自动转语音发送 |
| **语音转文字** | 本地 Whisper 模型，识别群友发的语音消息，转成文字给 AI |
| **永久记忆系统** | 成员档案（喜好/风格/口头禅）、共享备忘、会话上下文持久化，公开/私密分层，AI 可自主更新 |
| **15% 概率闲聊插话** | 不需要@也能自动回复，AI 自行判断是否接话 |
| **表情包自动发送** | AI 自主选择表情，支持插入位置控制（1-5 可选） |
| **消息合并防抖** | 连续消息 8 秒内合并成一次回复，避免多条回复混在一起 |
| **多用户消息区分** | 合并时保留每条消息的发送者，不会张冠李戴 |
| **时间戳标注** | 上下文带月日时分，AI 知道消息是什么时候发的 |
| **Token 余额查询** | @机器人发 `token` 查询剩余额度和当前时段 |
| **随机延迟防检测** | 发送消息前随机等待 1-8 秒，模拟真人打字 |
| **新人欢迎 / 随机冒泡** | 群成员入群欢迎，定时随机冒泡活跃气氛 |

### 🔧 附属功能

| 功能 | 说明 |
|---|---|
| **抖音视频/图文下载** | 独立 DTK 解析服务，无水印 1080p 视频，图文原图打包发送 |
| **汽水音乐下载** | 自动检测 VIP 歌曲（30秒/60秒试听拦截），支持强制下载试听版 |
| **本子下载** | 群/私聊直接发「下载本子\<ID\>」，支持选章节，完成自动清理 |
| **下载任务总开关** | 配置文件一键开启/关闭所有下载任务 |
| **ASR CPU 占用保护** | 语音识别前检测 CPU，超过安全阈值自动跳过 |
| **回复风格限制** | 限制回复长度和分段，像真人水群而不是机器小作文 |

详见项目内的 `README-Docker.md` 和 `README-Douyin.md`。

### 架构

```
qq-napcat      ← QQ 协议端（消息收发）
qq-bot          ← AI 主程序（对话/多模态/记忆/下载）
qq-controller   ← 远程控制端
dtk-api/worker/redis/postgres/downloader  ← 抖音独立解析服务
```
